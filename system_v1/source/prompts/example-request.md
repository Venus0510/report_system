```
页面标题: 封面

内容:
  - 主标题: 宏利活期友货币B
  - 副标题: 月度收益归因分析报告

  - 团队: 容诚估值团队
```

### 第2页：核心指标概览

```
页面标题: 一、本月核心指标概览
布局: grid-4 + full（上四列KPI卡 + 下折线图）
内容:
  - [x] KPI指标卡 × 4 个
    指标1: 七日年化收益率（数据字段: seven_day_yield）
    指标2: 万份收益（数据字段: nav_return_per_10k）
    指标3: 基金规模AUM（数据字段: aum）
    指标4: 平均偏离度（数据字段: deviation_bps）

  - [x] 折线趋势图 × 1 个
    标题: 七日年化收益率 & 偏离度 日频走势
    主轴数据: 七日年化（字段: seven_day_yield）
    副轴数据: 偏离度（字段: deviation_bps，单位bp）
    同业对比: 同业均值（字段: 来自peers_time_series.csv，虚线）
```

### 第3页：资产配置分析

```
页面标题: 二、资产配置分析
布局: split-left-right（左右各半）
内容:
  - [x] 环形占比图 × 2 个
    标题(左): 资产类别占比（目标 vs 同业）
    分类: asset_type（字段: asset_type / allocation_pct）
    标题(右): 债券类型占比（目标 vs 同业）
    分类: bond_type（字段: bond_type / allocation_pct）

  - [x] 柱状对比图 × 1 个（下方通栏）
    标题: 资产类别配置 vs 同类均值
    目标数据: 目标基金（字段: allocation_pct）
    对比数据: 同类均值（字段: peer_avg_pct）
```

### 第4页：收益归因分析

```
页面标题: 三、收益归因拆解
布局: full
内容:
  - [x] 归因分析表 × 1 个
    类型: 归因分析表
    因子: 票息收益 / 杠杆套息 / 交易骑乘 / 正偏离释放 / 费用摊薄 / 申赎冲击
    输出: 各因子贡献bp + 贡献占比 + 主要驱动说明

  - [x] 流程步骤 × 3 个（底部）
    步骤1: 核心驱动 → 票息收益贡献64.8%，存单+短融加权YTM维持高位
    步骤2: 风险关注 → 偏离度均值5.2bp，正偏离储备充裕但呈下降趋势
    步骤3: 管理建议 → 关注月末申赎冲击，维持杠杆率在1.05-1.10x区间
```

### 第5页：同业对比

```
页面标题: 四、同业对比分析
布局: full
内容:
  - [x] 同业对比表 × 1 个
    类型: 同业对比表
    对比维度: 七日年化 / 万份收益 / 管理费率 / 规模 / 偏离度 / 存款占比
    对比对象: 目标基金 vs 竞品A/B/C/D vs 同类均值
    highlight: 目标基金列

  - [x] 散点图 × 1 个
    标题: 业绩 vs 偏离度 | 同类基金定位
    X轴: 季度万份收益总额（字段: quarterly_return_per_10k）
    Y轴: 平均偏离度（字段: avg_deviation_bps）
    highlight: 目标基金（红色菱形标注）
```

## 四、数据来源

```yaml
数据文件:
  - 文件路径: data/fund_info.csv
    用途: 基金基本信息（名称、代码、费率）
    关键字段:
      - fund_code: 基金代码
      - fund_name: 基金名称
      - management_fee_pct: 管理费率
      - custodian_fee_pct: 托管费率
      - is_alipay: 是否支付宝

  - 文件路径: data/target_time_series.csv
    用途: 目标基金日频时间序列
    关键字段:
      - date: 日期（YYYY-MM-DD）
      - seven_day_yield: 七日年化收益率(%)
      - nav_return_per_10k: 万份收益
      - aum: 基金规模(元)
      - leverage_ratio: 杠杆率
      - deviation_bps: 偏离度(bp)

  - 文件路径: data/peers_time_series.csv
    用途: 同业均值日频数据
    关键字段:
      - date: 日期
      - avg_seven_day_yield: 同业均值七日年化

  - 文件路径: data/df_assets.csv
    用途: 资产配置（季度）
    关键字段:
      - report_date: 报告日期
      - asset_type: 资产类别
      - allocation_pct: 配置占比(%)

  - 文件路径: data/df_bond.csv
    用途: 债券类型配置（季度）
    关键字段:
      - report_date: 报告日期
      - bond_type: 债券类型
      - allocation_pct: 配置占比(%)
```
