# 业务需求输入卡

> **使用说明**：业务同事填写此卡，提交给AI，即可自动生成完整HTML报告/BI/网页。
>
> 标记 `[ ]` 为选项（改为 `[x]` 选中），标记 `___` 为填空。

---

## 一、基本信息

```yaml
报告标题: ___
副标题: ___
日期: 2026-XX-XX
作者/团队: 估值团队
输出文件名: ___.html
```

---

## 二、版式与风格

### 版式选择（四选一）

- [ ] **A4横版打印** — 仿PPT正式报告，page-by-page布局，支持打印导出PDF
  - 适用：月度分析报告、正式交付文档、打印归档
  - 文件：`layouts/a4-landscape.html`

- [ ] **全屏Slide演示** — 全屏翻页演示，带封面/目录/模块分隔页
  - 适用：会议汇报、培训材料、演示场景
  - 文件：`layouts/slides-fullscreen.html`

- [ ] **长滚动网页** — 自由长度网页，适合对外展示
  - 适用：产品介绍页、Landing Page、对外发布
  - 文件：`layouts/web-scrolling.html`

- [ ] **BI仪表盘** — 交互式数据分析看板，支持CSV数据加载
  - 适用：数据分析、同业对比、手搓BI原型
  - 文件：`layouts/bi-dashboard.html`

### 风格选择（四选一）

- [ ] **清爽商务风** — 蓝白调，简洁专业
  - 文件：`tokens/theme-business.css`
- [ ] **企业蓝白风** — 深蓝+天蓝，大气正式
  - 文件：`tokens/theme-corporate.css`
- [ ] **暗色科技风** — 深色背景，科技感
  - 文件：`tokens/theme-darktech.css`
- [ ] **金融专业风** — 青绿调，适合数据分析
  - 文件：`tokens/theme-finance.css`
