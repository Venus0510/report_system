每类资产统一从“技术方案、难点应对、审阅策略”三个维度展开，既体现专业深度，也回应大规模交付的现实问题。

非上市股权：直投与子基金投资

重点：财务数据更新滞后 + 估值方案一致性

技术方案

  • 根据投资阶段、可获得信息和退出路径选择市场法、收益法或资产基础法。
  • 核心参数包括可比公司/交易、收入利润预测、折现率、流动性折扣、控制权调整等。
  • 对子基金投资可结合基金净值、底层资产穿透信息及后续事项综合判断。

难点应对

  • 被投企业财务数据滞后或未经审计时，建立替代证据的采纳标准与程序。
  • 对管理层预测进行商业合理性、历史偏差和行业对标分析。
  • 对少数股权、锁定期、退出不确定性等进行情景化判断。

审阅策略

  • 按投资金额、估值变动、信息质量和行业风险进行分层。
  • 高风险项目逐项复核，中风险抽样复核，低风险进行规则化校验。
  • 梳理维护财务及融资信息，形成关键假设与参数规则，实现批量重估+特殊处理留痕。

上市项目

重点：市场价格可得但调整判断关键

技术方案

  • 以活跃市场报价为基础，结合持有限制、交易活跃度和大宗减持影响进行调整。
  • 核心参数包括收盘价/VWAP、限售折扣、流动性折扣、汇率及后续事项。
  • 对停牌、异常波动或低流动性证券采用辅助估值模型。

难点应对

  • 判断报价是否代表有序交易。
  • 处理估值日附近重大事件、监管事项或流动性急剧变化。
  • 对限售、质押、减持约束等非价格因素进行证据化说明。

审阅策略

  • 系统批量抓取价格并自动校验异常波动。
  • 对价格偏离、停牌、限售和重大公告项目列为重点审阅。
  • 低风险上市项目采用自动化复核与例外报告。

不良资产

重点：抵押物价值重估与压力情景分析

技术方案

  • 基于抵质押物、债务人偿付能力、诉讼进展和处置周期构建回收现金流模型。
  • 核心参数包括回收率、处置折扣、回收时间、费用率、折现率等。
  • 必要时采用多情景加权或压力情景分析证明财务估值审慎性。

难点应对

  • 抵押物价值涉及特种评估，房地产、信托受益权、使用权资产需区别对待。
  • 结合历史回收数据对回收预测合理性进行研判。
  • 对主观判断较强的处置假设进行专家复核、证据分级和加压评估。

审阅策略

  • 按本金余额、抵押物覆盖、逾期年限和法律状态进行风险排序。
  • 大额/异常/诉讼关键节点资产逐项审阅。
  • 同类资产采用组合参数校准并抽样验证，长年服务下开展估值回溯。

ABS

重点：判断底层资产类型、优先/劣后区别处理

技术方案

  • 基于底层资产现金流、分层结构、信用增级和触发机制建立估值模型。
  • 核心参数包括违约率、提前偿付率、回收率、利差、折现曲线和结构化分配规则。
  • 对优先/夹层/次级分层分别测算风险收益特征。

难点应对

  • 区分ABS发行场所，收集发行说明书、管理人定期报告等数据。
  • 底层资产数据颗粒度不足时，使用组合统计、外部评级和同类产品数据辅助。
  • 对触发事件、增信安排和服务机构表现进行专项核查。

审阅策略

  • 对结构复杂、次级持仓、评级变化和现金流偏离项目重点复核。
  • 批量校验模型分配逻辑和现金流瀑布。
  • 建立关键参数敏感性分析模板。

债权资产

重点：信用风险与利率风险分解

技术方案

  • 采用贴现现金流模型、市场收益率法或信用利差法进行估值。
  • 核心参数包括合同现金流、基准利率曲线、信用利差、违约概率、回收率和期限结构。
  • 对非标债权结合借款人信用、担保措施和还款安排进行定制化建模。

难点应对

  • 非公开债权缺乏直接市场报价，需要建立信用映射与可比利差。
  • 担保、展期、重组或附加条款影响现金流判断。
  • 对信用恶化迹象建立定量与定性触发指标。

审阅策略

  • 按评级变化、逾期状态、担保覆盖、收益率偏离进行风险筛选。
  • 标准化债权批量模型复核，非标债权重点抽样。
  • 对重大信用事件进行专项底稿和后续事项检查。

大批量估值的现实交付路径

系统性维护资产信息、配置估值参数，实现批量化重估。通过风险识别、分层审阅和例外管理，把资源集中在影响财务报告的核心估值风险。

01 资产数据治理统一字段、口径、资产类型、金额、估值日和责任人。
02 风险分层打标基于金额、波动、信息质量、模型复杂度和重大事项生成风险标签。
03 模型与参数复核标准资产批量校验，复杂资产逐项审阅，形成参数一致性控制。
04 例外报告与沟通输出高风险清单、估值调整建议、管理层判断事项和审计沟通材料。
