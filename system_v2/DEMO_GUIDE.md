# 金融报告 HTML 生成工具 — 指南

> 适用于：业务同事 · 领导演示 · 首次使用
> 阅读时间：约 5 分钟

---

## 一、这个工具解决什么问题

以前做一份专业的金融报告，你可能需要：

- 在 PPT 里一页页手动排版
- 反复调整字体、颜色、卡片位置
- 图表和数据要另外截图粘贴
- 想做网页版/手机版？基本不可能
- 团队之间格式不统一，每份报告重新做

现在用这个工具：

| 痛点 | 解决方式 |
|------|---------|
| 排版耗时 | **AI 自动生成**，你只需描述内容和选组件 |
| 风格不统一 | 内置**3套风格 + 3种版式**，一键套用 |
| 不懂 HTML | 用**自然语言**描述修改，AI 帮你改代码 |
| 电脑/手机/iPad 都要看 | 生成的 HTML **自动响应式**，打开即看 |
| 历史版本混乱 | 每次生成**自动保存版本**，随时回退 |

**一句话总结：你负责内容和想法，AI 负责排版和技术。最终得到一份可以独立打开的精美 HTML 报告。**

---

## 二、整体流程（3 步走）

```
浏览资源库 → 填写提示词 → AI生成 → 预览修改 → 导出报告
```

---

## 三、第一步：浏览资源库（心里有数）

在正式开始做报告之前，建议先花 2 分钟浏览一下**左侧菜单"资源库"**下的三个页面：

### 版式库（📐）
展示三种报告版式，决定你的报告"长什么样"：

| 版式 | 适用场景 | 特点 |
|------|---------|------|
| **A4 横版分页** | 正式交付、打印归档、高管汇报 | 像精美报告书，可打印为 PDF |
| **PPT Slide 翻页** | 内部培训、演示汇报 | 全屏翻页，键盘/点击切换 |
| **自由滚动网页** | 在线展示、Landing Page | 响应式长页，手机也能看 |

> 每种版式都有可视化预览，一眼就能看懂。

### 风格库（🎨）
展示三种配色方案，决定你的报告"什么气质"：

| 风格 | 适合场合 |
|------|---------|
| **商务蓝白** | 正式汇报、客户交付、高管看 |
| **暗黑科技** | 技术方案、数据报告 |
| **清新简约** | 培训材料、内部文档 |

> 每种风格都有真实卡片渲染效果，不是抽象色块。

### 组件库（🧩）
展示所有可用的"积木块"，点击可看代码：

- **KPI 数字卡片** — 大数字 + 标签 + 变化趋势
- **信息卡片** — 标题 + 正文描述
- **数据表格** — 标准表格，蓝色表头
- **流程步骤条** — 带编号的步骤列表
- **对比卡片** — 左右双栏对比
- **团队介绍网格** — 头像 + 角色卡片
- **亮点引用** — 引用金句
- **大数字行** — 一行多个并列指标

> 这些都是 AI 会参照的"模板"，你选的组件越多，AI 生成的越贴合你的需求。

---

## 四、第二步：生成提示词（告诉 AI 你要什么）

点击左侧菜单 **「✏️ 生成提示词」**，按步骤填写：

### Step 1 — 报告基本信息

- **报告文件名**：给报告起个名字，如 `货币基金月度报告`。后面所有生成版本都会以此命名。
- **报告主题**：一句话说清这份报告要讲什么。
- **受众**：高管 / 客户 / 内部 / 项目
- **用途**：汇报展示 / 培训材料 / 交付文档

> 你写的主题可以是粗略想法，AI 会自动扩展为专业文案。

### Step 2 — 选择版式

点击卡片选择你想要的版式。不确定？先去版式库看看效果再回来选。

### Step 3 — 选择风格

点击色块选择配色方案。同样可以先看风格库再决定。

### Step 4 — 配置内容结构（最重要）

这里根据你选的版式，界面会不同：

- **A4 版式**：逐页添加。每一页你填"这页大概写什么" + "用哪些组件"
- **PPT 版式**：逐节添加。每个演讲主题一"节"，你还可以建议 AI 拆成多少页 slide
- **网页版式**：逐区块添加。典型区块有 Hero 首屏、核心服务、案例成果

> 不用担心写得不专业。你只需要用大白话描述想法，比如"这里展示一下基金表现，看起来还不错"，AI 会自动翻译成报告语言。不确定的具体数字会自动标记为 [待填数据]，不会编造。

每个组件显示的是**真实渲染效果**，不是抽象图标。选之前能看到它长什么样。

### Step 5 — 数据来源

- **上传 CSV**：拖一个 CSV 文件进来，系统自动解析
- **手写 JSON**：粘贴数据
- **占位数据**：还没整理好数据？先不用填，AI 会用示例数据生成，后面再替换

### 一键复制

点击「🪄 生成提示词」→「📋 一键复制」。**复制后不要刷新页面！**（刷新会丢失表单数据）

---

## 五、中间的 AI 环节（在 Claude 桌面端完成）

把复制好的提示词粘贴到 **Claude 桌面端** 的对话框中，发送。

Claude 会：
1. 自动生成完整的 HTML 报告
2. **自动将文件保存到 `reports/` 目录**（文件名格式：`你的报告名_v001_时间.html`）

> 提示词里已经嵌入了保存路径指令，Claude 会自动写文件，不需要你手动复制粘贴 HTML。

---

## 六、第三步：预览修改（看到效果、迭代完善）

回到工具，点击 **「👁️ 预览修改」**。

### 查看版本
- 顶部显示所有历史版本（`v001 · 时间 · 大小`）
- 点击某个版本 → 自动加载到预览区

### 预览效果
- 左侧预览区实时渲染你的报告
- 顶部可切换设备视图：**桌面 / iPad / 手机**，检查响应式效果
- **hover 任意元素 → 蓝色高亮框**
- **click 任意元素 → 右边编辑器自动跳转到对应代码行**

### 修改内容
有两种方式：

**方式一：自然语言（推荐给非程序员）**
在「修改意见」里用大白话描述要改什么：
- "把第2页的3个卡片改成4个"
- "标题颜色太深了，改浅一点"
- "这部分的语气正式一些"

→ 点击「生成指令」→「复制到剪贴板」→ 粘贴回 Claude → Claude 生成新版本并保存

**方式二：直接改代码（适合懂一点 HTML 的同事）**
在右侧 HTML 编辑器中直接修改，点击「更新预览」即时看效果。`Ctrl+S` 保存。

### 版本追溯
每次 Claude 生成新版本，点「🔄 刷新列表」就能看到新版本。所有版本都保留，随时回退。

---

## 七、第四步：导出（交付最终报告）

点击 **「📦 导出下载」**，三种导出方式：

| 方式 | 适用场景 |
|------|---------|
| **下载 HTML 文件** | 得到一个 `.html` 文件，双击就能在浏览器打开，可以发给同事或客户 |
| **打印为 PDF** | A4 版式最适合，弹出打印对话框后选「另存为 PDF」 |
| **复制源码** | 需要把 HTML 代码粘贴到其他平台 |

导出前建议检查：
- 已看过桌面/平板/手机三种效果
- 数据已确认
- 标题/日期/落款已更新

## 八、使用注意事项

### 启动方式
- 双击项目文件夹里的 **`start.command`** 文件，浏览器自动打开
- 工具运行时**不要关闭那个终端窗口**（关了就停止服务了）
- 浏览器访问地址：`http://localhost:8080`

### 工作流提醒
- 提示词复制后**不要刷新浏览器**，表单数据会丢失
- Claude 生成的 HTML 文件自动保存在 `reports/` 目录，不会丢失
- 每次修改后记得在预览页点「🔄 刷新列表」加载最新版本
- 如果不确定 AI 输出效果，先用一两页报告测试，再扩展到正式版本

### 最佳实践
- **先想清楚再动手**：确定报告主题、受众、版式 → 浏览组件库找到合适积木 → 填写提示词
- **小步迭代**：先生成第一版看效果 → 不满意就改 → 复制新版本 → 满意后导出
- **数据后填**：如果数据还没整理好，先用占位数据生成框架，数据准备好了再让 AI 替换
- **风格最后定**：内容确认后再切换风格看效果，不用一开始纠结配色

### 文件管理
- `reports/` 目录可以当版本库用
- 完成了的报告把 `.html` 文件发出去即可，对方不需要任何工具
- 重要报告的配置可以保留，下次做类似报告直接加载

## 九、常见问题

**Q: 我完全不懂代码，能用吗？**
A: 可以。你只需要选版式、选组件、用大白话描述内容。HTML 代码由 AI 生成，你不需要写一行代码。

**Q: 报告里的图表怎么办？**
A: AI 生成 HTML 时可以用 ECharts（一个 JS 图表库）画图。如果你的数据是 CSV，AI 会直接读取并绑定到图表上。

**Q: 生成的报告能在手机上打开吗？**
A: 可以。工具内置了设备预览切换，确保生成的是响应式 HTML。手机、iPad、电脑打开效果都适配。

**Q: 做错了能回退吗？**
A: 可以。每次 AI 生成都是新版本（v001、v002...），所有历史版本都在预览页的版本标签栏里，随时切换。

**Q: 工具需要联网吗？**
A: 工具本身不需要（本地运行），但 Claude 生成 HTML 需要网络。工具用的是 CDN 加载 Vue/Tailwind 等库，首次打开需要网络。

**Q: 别人怎么看我做的报告？**
A: 下载的 `.html` 文件是独立的，发给任何人双击打开就能看，不需要安装任何东西。

## 十、未来可扩展方向（欢迎提建议 🚀）

当前系统是 V1.0，已跑通核心流程。以下是可以持续迭代的方向，**看完欢迎提新想法**：

### 资源生态

| 方向 | 说明 | 价值 |
|------|------|------|
| **更多组件** | 图表卡片、环形进度、时间轴、组织架构图、甘特图等 | 覆盖更多报告场景 |
| **更多风格** | 政务红金、极简黑白、学术典雅、品牌定制色等 | 匹配不同行业和场合 |
| **更多版式** | A4竖版、16:9宽屏、信纸格式等 | 满足特殊排版需求 |
| **组件在线编辑器** | 可视化调整组件参数（颜色、数据、文字），不用写代码 | 降低使用门槛 |

### 流程体验

| 方向 | 说明 | 价值 |
|------|------|------|
| **AI 对话内嵌** | 不用在工具和 Claude 之间来回粘贴，工具内直接对话 | 操作更流畅 |
| **多轮对话记忆** | AI 记住你的修改偏好和历史，越改越懂你 | 修改效率翻倍 |
| **报告配置模板** | 保存"月度基金报告""客户方案书"等常用模板，一键套用 | 重复工作变快 |
| **多人协作编辑** | 同一份报告多人在线评论、修改 | 团队流程打通 |

### 数据能力

| 方向 | 说明 | 价值 |
|------|------|------|
| **数据库/API 接入** | 直接从内部系统取数，不用手动上传 CSV | 数据实时、准确 |
| **数据自动更新** | 报告里的数字和图表随数据源自动刷新 | 报告变为"活文档" |
| **图表交互增强** | 下钻、筛选、切换时间维度等 | 从静态报告到轻量 BI |

### 业务对接

| 方向 | 说明 | 价值 |
|------|------|------|
| **AI 生成 HTML → 自动转 Vue 组件** | 业务侧做好的报告，开发端直接对应用 Vue 组件重写嵌入系统 | 业务和开发一体化 |
| **资源库与系统组件库互通** | 业务用的组件和开发用的 Vue 组件一一对应，维护配套 | 减少重复建设 |
| **合规与审批** | 报告审批流程、数据脱敏、操作日志 | 满足金融合规要求 |
