## 三、任务视图（甘特图）

### 3.1 日期编码方案

所有日期计算使用**绝对天数**（`toDayNum`），消除时区问题：

```javascript
function toDayNum(dateStr) {
  var parts = dateStr.split('-');
  var d = new Date(parseInt(parts[0]), parseInt(parts[1]) - 1, parseInt(parts[2]));
  d.setHours(0, 0, 0, 0);
  return Math.round((d.getTime() - d.getTimezoneOffset() * 60000) / 86400000);
}
```

- `periodStartNum()` = 当前窗口起始日（周一）的绝对天数
- `windowEndNum()` = `periodStartNum() + 13`
- 存储格式仍为 `YYYY-MM-DD` 字符串（兼容 IndexedDB），计算时转换为绝对天数

### 3.2 日期表头

| 元素 | 说明 |
|------|------|
| **星期** | 周一~周日，周末列有灰色背景 |
| **日期数字** | 等宽数字字体，今天为绿色圆形高亮 |
| **月份标记** | 第一列或每月1日显示"X月"小标 |
| **日总工时** | 当天所有任务工时之和，无任务时不显示 |
| **周分隔线** | 第8列（第二周周一）左侧有分隔线 |
| **选中高亮** | 点击日期头打开分配弹窗时，该列显示绿色边框高亮 |

### 3.3 网格列

- 14 列等宽（百分比定位），响应式自适应
- 周末列：浅灰背景
- 周分隔线：第 8 列左侧有边框线
- 今日线：红色半透明竖线贯穿网格，仅当今天在窗口内时显示
- 选中列：与日期表头选中状态同步高亮

### 3.4 任务条块

| 元素 | 说明 |
|------|------|
| **条块位置** | 根据 `startDate` / `endDate` 计算跨列数，绝对定位百分比 |
| **条块颜色** | 按所属项目颜色（`projectColor`），左侧 4px 边框色（`borderColor`） |
| **条块内容** | 任务名称 + 自动计算的总工时（如 `40.0h`） |
| **拖拽把手** | 条块两端有 8px 宽的拖拽把手（`gantt-handle`），hover 时高亮 |
| **裁剪标记** | 任务起止日期超出窗口边界时，对应端圆角变平（`clipl`/`clipr`），隐藏把手 |

### 3.5 甘特图底部栏

- 显示当前视图下可见任务数 + 总工时
- 格式：`5 个任务 · 合计 120.0h`

## 四、拖拽系统

### 4.1 拖拽模式

| 模式 | 触发区域 | 行为 | 约束 |
|------|---------|------|------|
| **create** | 网格空白区域横向拖拽 | 拉出预览条，释放后弹出创建对话框 | 不超出窗口边界 |
| **move** | 拖拽任务条中间区域 | 水平移动整段任务，长度保持不变 | 起止位置均不超出窗口 |
| **resize-l** | 拖拽任务条左把手 | 调整开始日期 | 不超过结束日期，不超出窗口 |
| **resize-r** | 拖拽任务条右把手 | 调整结束日期 | 不小于开始日期，不超出窗口 |

### 4.2 拖拽状态

```javascript
dragState = {
  mode: 'create' | 'move' | 'resize-l' | 'resize-r',
  taskId: string,       // move/resize 时的任务 ID
  start: number,        // create 时的起始列索引 (0-13)
  end: number,          // create 时的结束列索引 (0-13)
  origStart: number,    // move/resize 时的原始开始绝对天数
  origEnd: number,      // move/resize 时的原始结束绝对天数
  grab: number,         // move 时的抓取点绝对天数
  moved: false          // 是否实际发生了位移
}
```

### 4.3 拖拽流程

1. `pointerdown` 在网格上 → `onGridDown(e)`
   - 若在 `.gantt-handle` 或 `.gantt-bar` 上 → 识别为 move/resize
   - 否则 → 识别为 create
2. `pointermove` → `_handleMove(e)` → 实时更新位置/日期
3. `pointerup` → `_handleUp()` →
   - create → 弹出拖拽创建对话框
   - move/resize 未位移 → 打开任务编辑弹窗
   - move/resize 有位移 → 刷新工时计算 + 保存

### 4.4 预览条

- create 模式时显示虚线预览条
- 位置跟随拖拽起止列
- 文字显示跨天数（如"5天"）

## 五、工时自动计算

### 5.1 核心算法

与 `timesheet-tracker.html` 完全一致：

```
defaultHoursForDay(abs)  = 8h ÷ 当天任务数    （平均分配）
dayHoursFor(abs, taskId) = overrides["abs:taskId"] ?? defaultHoursForDay(abs)
ganttTaskHours(task)     = Σ dayHoursFor(d, task.id) for d in [start, end]
dayTotalHours(abs)       = Σ dayHoursFor(abs, t.id) for t in tasksOnDay(abs)
```

### 5.2 覆盖机制（Overrides）

- 存储在 `dayOverrides` 对象中，key 为 `"absDay:taskId"`
- 用户在日期分配弹窗中手动调整后，差异值写入 overrides
- 若用户将值改回默认值（误差 < 0.01），删除该条 override 以节省存储
- 使用 `$set` / `$delete` 确保 Vue 响应式

### 5.3 触发时机

- 拖拽移动/缩放任务后 → `refreshAllTaskHours()` → 重新计算所有未完成任务
- 日期分配弹窗保存后 → 同上
- 删除任务后 → 清理相关 overrides → 刷新剩余任务工时
- 批量创建任务后 → 同上

### 5.4 显示位置

- 任务条块上：自动计算的 `ganttTaskHours(task)`，非 `estimatedHours` 字段
- 日期表头上：当天总工时 `dayTotalHours(abs)`
- 底部栏：所有可见任务合计

## 六、点击交互

### 6.1 日期表头点击

- 打开「日期工时分配」弹窗（Element UI Dialog）
- 显示当天所有重叠任务的列表
- 每行：色块 + 任务名 + 工时输入框（默认 = dayHoursFor 当前值）
- 支持"平均分配"按钮（8h ÷ 任务数）
- 顶部显示总工时 / 8h，超过 8h 时变红
- 点击日期头后列高亮，关闭弹窗后自动取消高亮

### 6.2 任务条点击

- 打开「任务编辑」弹窗
- 可编辑：任务名称、所属项目、预估工时、完成状态
- 日期区间仅展示（通过拖拽调整）
- 支持删除任务（含二次确认）

### 6.3 拖拽创建

- 拖拽释放后弹出「新建任务」对话框
- 需选择：项目（下拉搜索）、任务名称
- 日期区间和预估工时由拖拽范围自动生成
- 创建后自动计算工时

## 八、"三个三秒"原则

| 动作 | 目标耗时 | 当前实现 |
|------|---------|---------|
| **三秒建任务** | ≤3秒 | 网格拖拽 → 选项目 → 输入名称 → 创建 |
| **三秒打勾** | ≤3秒 | 底部待办 → 填工时 → 点记录 → 勾完成 |
| **三秒看全貌** | ≤3秒 | 双周甘特图 + 团队热力图一键切换 |

## 九、关键设计决策

| 决策 | 理由 |
|------|------|
| **周一基准双周** | 对齐周会节奏，前3+今天+后10的固定偏移无法跨周导航 |
| **绝对天数编码** | 日期跨度计算变为整数减法，消除时区歧义，O(1) override 查询 |
| **8h/天均分** | 简单公平，支持手动覆盖精细化 |
| **拖拽即创建** | 所见即所得，比表单填写快 3 倍 |
| **实时工时计算** | 条块上显示的工时随拖拽/分配实时更新，信息始终准确 |
| **百分比定位** | 栅格自适应容器宽度，无需监听 resize |
| **单文件 CDN** | Vue2 + Element UI + Tailwind 全部 CDN，零构建 |
