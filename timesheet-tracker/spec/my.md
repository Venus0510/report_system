技术栈：vue2 element UI  Tailwind CSS，全部用cdn，零依赖
需求：
我在想要一个planner/tracker，
金融会计事务所估值团队，想要做项目进度、人员工时管理，目前的痛点是业务同事忙季时一天接十几个项目要做估值，可能就会忘记创建任务，也会忘记填报工时，每个人都很忙，但是没有体现出来工作量，领导虽然知道手底下的人在忙，但是具体不知道忙了什么，事情主要分为意向项目进度，投标进度，立项项目进度，一个项目集底下可能有不同类型的任务，领导不想大家已经在这么忙的情况下还要花很多时间精力去写任务填工时，最好是在开会的时候分配任务时以最快简单方便的方式把这一周的任务创建了，然后后面每天打个勾勾就把任务点完成并且填报到工时系统里去，怎么设计这一整套业务和交互
1. 整体定位

- MVP：做一个首页.html，专注"派活→打勾→填工时→团队任务看板"闭环

2. 核心流程

开会 → 批量派活（行式快填，项目集+时间自动继承上一行）
         → 同事打开首页 → 看团队概览条 + 自己日历
         → 每天干活 → 点任务 → 输小时数 → 回车
         → 领导随时看团队忙闲热力图 + 项目集工时归集

3. 所有确认的设计决策

派活模式         │ 批量为主      │ 行式快填，4必填字段：项目集、任务名、人员、时间

任务名           │ 快选+手填    │ 历史模板快选

人员选择         │ 单选          │ 多选拆多行

完成方式         │ 每日打勾        │ 一个任务一张卡片，完成就打勾自动填工时

工时填写         │ 勾选+小时   │ 输数字，有默认工时数→回车

首页布局         │ 日历型，两个tab切换，团队视图和个人视图 ｜ 行=任务，列=日期

团队概览信息     │ 项目进度+任务数 │ 

时间窗口         │  滚动14天   │ 前3+后11

日期区间         │ 可选   │ 填了=连续
