# 团队任务追踪器 — 方案设计

## 一、总体架构

单文件 `index.html`，Vue2 + Element UI + Tailwind CSS 全部 CDN 引入，零构建、零依赖。
数据用 `localStorage` 持久化，模拟阶段不写后端。

```
┌─────────────────────────────────────────┐
│  [团队视图] [个人视图]                    │  ← Tab 切换
│  日期导航: ◀  6/6 一  ...  6/19 日  ▶   │  ← 14天滚动 (前3+后11)
├─────────────────────────────────────────┤
│                                         │
│  [团队视图] — 热力图矩阵                   │
│  ┌────────┬────┬────┬────┬───    ───┐  │
│  │ 人员   │周一│周二│...           │  │
│  ├────────┼────┼────┼────┼───    ───┤  │
│  │ 张三   │ 4h │ 8h │    │ ...     │  │  ← 格子=工时，色深=忙闲
│  │ 李四   │    │ 2h │ 6h │ ...     │  │
│  └────────┴────┴────┴────┴───    ───┘  │
│                                         │
│  [个人视图] — 任务清单日历                 │
│  ┌────────┬────┬────┬────┬───    ───┐  │
│  │ 任务   │周一│周二│...           │  │

│                                         │
│  [+ 派活] 按钮 → 弹出批量派活抽屉         │
```

## 二、核心数据结构

```js
// 任务
tasks: [
  {
    id: 't001',
    project: '标书1',        // 项目集
    name: '技术方案撰写',     // 任务名
    assignee: '张三',        // 负责人（单选，多选拆多行）

    logs: {                  // 每日工时记录

      '2026-06-07': { hours: 3, done: false }

// 人员（简单数组）

// 项目集（带颜色）

  { name: '标书1', color: '#3b82f6' },
  { name: '网站投标', color: '#f59e0b' },
  { name: '技术方案', color: '#8b5cf6' }
]
```

## 三、首页布局 — 两个 Tab

### Tab 1: 团队视图（领导看）

**目标**：一眼看全团队忙闲，项目集工时归集

```
┌────────────────────────────────────────────────────────────┐
│  团队忙闲热力图                                              │
├──────────┬────────┬────────┬────────┬───────┬───────┬──────┤
│          │ 6/6 一 │ 6/7 二 │ 6/8 三 │ ... 14天         │
├──────────┼────────┼────────┼────────┼───────┼───────┼──────┤
│ 张三     │  ████  │  ████  │   ██   │                    │
│          │  8h    │  8h    │  4h    │                    │
├──────────┼────────┼────────┼────────┼───────┼───────┼──────┤
│ 李四     │        │  ████  │  ████  │                    │
│          │        │  6h    │  8h    │                    │
├──────────┼────────┼────────┼───────┼───────┼───────┼──────┤
│ ...      │        │        │        │                    │
└──────────┴────────┴────────┴────────┴───────┴───────┴──────┘

点击人员行 → 展开该人当天所有任务明细
```

**热力图规则**：
- 空格子 = 无任务 / 白色
- 1-4h = 浅蓝 `#dbeafe`
- 5-8h = 中蓝 `#93c5fd`
- 8h+ = 深蓝 `#3b82f6`
- 格子hover显示当天任务列表tooltip

**底部汇总条**：
```
今日总工时: 32h  |  活跃任务: 8  |  已完成: 3  |  [按项目集查看 ↓]
```

### Tab 2: 个人视图（同事干活）

**目标**：看我自己的任务，点格子打勾填工时

```
┌────────────────────────────────────────────────────────────┐
│  我的任务日历                                                │
├──────────────────┬────────┬────────┬────────┬───────       │
│  任务            │ 6/6 一 │ 6/7 二 │ 6/8 三 │ ...           │
├──────────────────┼────────┼────────┼────────┼───────       │
│  [蓝] 标书1      │   ✓    │  [3]   │        │               │
│  技术方案撰写     │  4h    │        │        │               │
│                  │(绿色=已完成)│(蓝色=有工时)│               │
├──────────────────┼────────┼────────┼────────┼───────       │
│  [橙] 网站投标   │        │        │   ✓    │               │
│  安全测试         │        │        │  6h    │               │
├──────────────────┼────────┼────────┼────────┼───────       │
│  [紫] 技术方案   │        │   ✓    │   ✓    │               │
│  迭代测试报告     │        │  8h    │  2h    │               │
└──────────────────┴────────┴────────┴────────┴───────       │
```

**格子交互**：

| 当前状态 | 点击行为 | 结果 |
|---------|---------|------|
| 空格子 | 单击 | 变 ✓，自动填默认工时 |
| 有 ✓ 有工时 | 单击 | 弹出input，可改工时数字 |
| input中 | 回车 / 失焦 | 保存，如果工时=0则取消完成 |
| 有 ✓ | 右键 / 长按 | 取消完成，清空工时 |

**任务行左侧**：项目色块小圆点 + 项目名（灰字小字）+ 任务名

## 四、派活抽屉（批量派活）

从右侧滑出的抽屉，行式快填：

```
┌─────────────────────────────────────────┐
│  批量派活                        [×]    │
├─────────────────────────────────────────┤
│  项目集    任务名      负责人    时间    │  ← 表头
│  ─────────────────────────────────────  │
│  [标书1▼] [技术方案▼] [张三▼] [6/6-6/10]│  ← 第1行
│  [标书1▼] [________] [李四▼] [6/6-6/10]│  ← 第2行（继承项目集）
│  [______] [________] [____] [________] │  ← 第3行（空行，+回车新增）
│  ─────────────────────────────────────  │
│                              [+ 添加行] │
│                              [确认派活] │
└─────────────────────────────────────────┘
```

**行式快填规则**：
1. 新增行自动继承上一行的「项目集」和「时间」
2. 任务名：下拉选历史模板 或 手填（手填的自动进模板库）
3. 负责人：单选下拉，多个人=拆多行（不允许多选）
4. 时间：Element 的 date-picker range，不填=14天全开放
5. 最后一行按回车 or Tab 到最后 → 自动新增空行
6. 至少填「项目集+任务名+负责人」才能保存

## 五、组件拆分

因为是单文件，按 Vue component 方式写在同一个 html 里：

```html
<!-- 根 -->
<app>
  <top-bar>           <!-- 标题 + Tab切换 + 日期导航 -->
  <team-view v-if="tab==='team'">   <!-- 团队热力图 -->
  <personal-view v-else>             <!-- 个人日历 -->
  <assign-drawer>     <!-- 派活抽屉 -->
  <project-summary>   <!-- 项目集工时汇总（团队视图底部） -->
</app>
```

## 六、视觉风格

参考日历.png的干净感：

- **背景**：`#f8fafc`（slate-50），内容区白色卡片
- **字体**：系统默认，中文优先 `PingFang SC`, `Microsoft YaHei`
- **圆角**：卡片 `rounded-lg(8px)`，按钮 `rounded-md(6px)`，格子内小圆点 `rounded-full`
- **边框**：极细 `border-slate-200`，不用重阴影
- **项目色**：4-5个柔和色，低饱和：蓝、橙、紫、青、粉
- **今日高亮**：日期列头部加浅黄底色 `bg-yellow-50`，或左边框
- **完成态**：格子内绿色小勾 `text-green-500`
- **行hover**：整行淡灰底色 `hover:bg-slate-50`

## 七、数据流

```
localStorage (唯一持久层)
    ↑↓
Vue data (tasks, members, projects)
    ↑↓
组件 props / events
    ↑↓
用户操作（点格子、派活、改工时）
```

- 每次操作后 `localStorage.setItem('planner_data', JSON.stringify(data))`
- 页面加载时 `localStorage.getItem` 恢复
- 初期不加后端，数据全在本地

## 八、14天日期计算

```js
// 今天 = 2026/06/09
// 显示: 前3天(6/6~6/8) + 今天(6/9) + 后10天(6/10~6/19) = 14天
const today = new Date()
const dates = []
for (let i = -3; i <= 10; i++) {
  const d = new Date(today)
  d.setDate(today.getDate() + i)
  dates.push(d)
}
```

日期头部格式：`6/9 周一`，周末（六/日）用淡灰字
