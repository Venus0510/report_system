## Claude Chat Manager，它的自动分组功能很实用，几乎不需要任何配置就能把对话记录整理得清清楚楚

npm install -g claude-chat-manager
claude-chat init

   1. 重启 Claude Code
   2. 开始对话，记录将自动保存到 chat_history/ 目录
   3. 运行 claude-chat web 启动可视化管理界面

💡 提示：

- 运行 claude-chat list 查看所有对话记录
- 对话记录按日期和主题自动分组
