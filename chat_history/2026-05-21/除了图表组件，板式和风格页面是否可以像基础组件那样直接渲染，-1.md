### 版式页面（Layout）→ 已改为内联 v-html 渲染

**之前**：iframe 加载 `layouts/xxx/index.html`，iframe 内是一整页（返回链接 + 标题 + 主题切换 + 预览），与 gallery 自身 UI 重复。

**现在**：
- 加载 `skeleton.html`（纯骨架 HTML），用 `v-html` 直接渲染到 `.layout-preview-box` 中

- 预览容器内做了缩放处理（A4 缩至 70%，PPT 适应固定高度等），适合在右侧面板查看
- 代码展示区仍然显示 skeleton.html 源码
- "全屏预览"按钮仍然可用，打开完整交互版

### 风格页面（Style）→ 已改为内联渲染 + 自动切主题

**之前**：iframe 加载 `styles/xxx/preview.html`，又是一个整页，重复 UI。

**现在**：
- 点击风格项时，**自动切换 gallery 的 `data-theme`** 到对应主题
- 显示**色彩系统色块**（10 个 CSS 变量实时读取，切换主题即时变色）
- 显示**组件示例网格**（KPI卡片 + 信息卡片 + 亮点引用 + 章节标题 + 分割线）
- 组件自动响应当前主题 CSS 变量，无需额外处理
- 手动切换顶部主题下拉框时，色块也会同步更新

### 图表（Chart）→ 保持 iframe（必须）

ECharts 需要独立 JS 执行环境，无法改为内联渲染。

### Token 预览 → 暂保持 iframe

结构相对独立且交互复杂，本次未改。但已修复了 iframe 缺少高度样式的问题。

| 风格 | iframe 整页 | 内联色块+组件 | ✅ 已消除 |

## 最终总结

所有页面类型现在都**不再使用 iframe**，没有页面重复问题，用户可以直接在 gallery 中浏览所有内容：

| 类型 | 渲染方式 | 说明 |
|------|---------|------|
| **基础组件** | `v-html` 内联 | 不变，CSS 变量即时响应 |
| **图表** | `v-html` + ECharts JS 初始化 | 已加载 ECharts CDN，Vue 中调用 `echarts.init()` 渲染，切换主题自动重绘 |
| **版式** | `v-html` 内联 + 缩放 CSS | A4 缩放至 77%、PPT 三页垂直排列、Web Scroll 正常流式布局，含真实 demo 内容 |
| **风格** | 色块矩阵 + 组件示例 | 点击自动切换 `data-theme`，实时读取 CSS 变量显示 10 个色块 + 5 个示例组件 |
| **Token** | 内联色块/字体/间距/圆角/阴影 | 完全取代原 iframe，5 个面板展示全部设计规范 |

### 关键技术点
- **图表**：`selectItem` 中同步设置 `currentCode`（fallback HTML），`$nextTick` 中调用 `initChart()` 实时初始化 ECharts，避免异步竞态
- **主题切换**：`onThemeChange` 中自动重绘图表、重建 token/风格预览
- **实例清理**：切走时 `chartInstance.dispose()` 避免内存泄漏
- **版式**：PPT 用 `display:flex!important` 覆盖 `.ppt-slide+.ppt-slide{display:none}`，三页垂直排列展示；A4 用 `font-size:77%` 缩放预览
