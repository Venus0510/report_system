## 改动内容

### 合并按钮
- **删除** 底部「复制代码」按钮（原来只复制裸 HTML，无规范上下文）
- **删除** 右侧「复制组件信息」按钮（原来只复制元数据，无实际代码）
- **新增** 统一的「📋 复制提示词」按钮（右上角，替换原"复制组件信息"）

### 新提示词结构

复制的提示词包含三部分，AI 拿到即可准确复现：

**1. 设计规范头部（所有类型通用）**
- 颜色规则：CSS变量清单 + 禁止硬编码/Tailwind颜色
- 布局规则：Tailwind 仅布局，圆角阴影用 CSS 变量
- 标识规则：`data-cid` 必须保留
- 主题系统：`data-theme` 切换 + Design Token 参考值

**2. 选中项详情（按类型定制）**

| 类型 | 包含内容 |
|------|---------|
| 组件 | 名称/ID/路径 + Props 接口 + **template.html 完整代码** |
| 图表 | 容器HTML + Props + **ECharts 初始化规范**（含 getComputedStyle 配色模式） |
| 版式 | 尺寸/翻页/场景 + **skeleton.html 完整骨架** |
| 案例 | 主题/版式/组件清单 + **案例完整HTML** |
| 风格 | CSS变量当前值 |
| Token | 全部CSS变量值（颜色/字号/间距/圆角/阴影） |

**3. 任务占位符**
```
[ 请在此处描述你的具体需求，例如：生成一份货币基金月度报告的封面页... ]
```

### 用户使用流程
